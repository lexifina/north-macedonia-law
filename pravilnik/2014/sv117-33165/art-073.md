# Член 73
Во член 131 по ставот 1 се додава нов став 2, кој гласи:
„За вршење на полициските работи од ставот 1 на овој член, од страна на лицата определени во член 138 став 2 од овој правилник се издава писмената наредба од член 73 став 3 од овој правилник.“
Ставовите 2 и 3 стануваат ставови 3 и 4.
