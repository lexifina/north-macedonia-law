# Член 3
Спојката на возилата - цистерни која обезбедува врска со товарната постројка треба да има четири инчен машки адаптер (101,6mm) определен согласно техничката спецификација за долно полнење и собирање на испарувањето како што се опремени возилата цистерни МС-306 според: API (American Petroleum Institute) Препорачана пракса 1004 Седмо издание, ноември 1988 - поглавје 2.1.1.1 - Адаптер за одвод на испарувањата.
