# Член 7
Сервис од општ формат кој претежно исполнува една функција
Во телевизискиот програмски сервис од општ формат во кој застапените видови програми претежно исполнуваат една од трите медиумски функции, функцијата што претежно се исполнува не смее да биде застапена со помалку од 50%, ниту со повеќе од 65%. Останатиот дел од програмата го сочинуваат програми што ги исполнуваат другите две медиумски функции, при што ниту една од овие две функции не смее да биде застапена со помалку од 5% во вкупната емитувана програма во текот на една седмица.
