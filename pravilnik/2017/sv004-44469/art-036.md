# Член 36
Превоз со железница, превоз по патишта, превоз по воздушен пат и превоз по вода на
гравидни говеда
За гравидните говеда при превоз со железница, превоз по патишта, превоз по воздушен пат и превоз по вода треба да се обезбеди 10% повеќе простор од просторот пропишан во членот 35 од овој правилник.
