# Член 23
3.3. Материјални услови
Максималниот број на поени од материјалните услови е 18 поени и тоа по основ на: -
работен однос/пензија
- обработка на земјоделско земјиште
- вршење занатски работи
- вршење надничарски работи
- врши друг вид на работи
- остварува приходи по други основи
Ако можниот посвоител по било кој основ од неведените, остварува: - минимум средства за егзистенција 0 - средства за пристоен живот 12,75 - максимум средства за егзистенција 17 Поседува/ат: 1
