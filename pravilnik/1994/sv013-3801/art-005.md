# Член 5
Заради проверка на искажаните податоци, пополнетиот образец оУВПо претпријатието го доставува до:
1. Министерството за одбрана, за средствата од член 3, точка 1;
2. ресорните министерства (зависно од изворот на средствата) за средствата од член 3, точка 2 и 5;
3. Министерството за развој, за средствата од член 3, точка 3;
4. Министерството за финансии за средствата од член 3, точка 4.
