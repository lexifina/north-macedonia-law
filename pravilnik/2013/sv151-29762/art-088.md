# Член 88
За параметри кои ја одредуваат врската помеѓу Меѓународниот инерцијален референтен систем ( International Celestial Reference System -ICRS) и Меѓународниот терестички референтен систем (International Terestrial Reference Frame -ITRF) се усвојуваат вредностите кои ги објавува Меѓународната служба за земјина ротација (International Earth rotation and Reference systems Service - IERS) .
