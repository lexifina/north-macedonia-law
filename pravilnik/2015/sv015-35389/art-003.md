# Член 3
Податоците покрај во читлив формат се објавуваат и како необработени податоци во компјутерски обработлив формат и се достапни во отворен формат заедно со нивните мета-податоци до најниското ниво на деталност.
Формати за објавување на платформата за отворени податоци се:
- XLS (Microsoft Office Excel),
- XLSX,
- CSV (Comma Separated Values),
- XML (Extensible Markup Language),
- JSON (JavaScript Object Notation) и
- Web services - API (Application Programming Interface).
Покрај форматите од ставот 2 на овој член од страна на органите и институциите од јавниот сектор може да се воспостави директен пристап за преземање на податоци од следните типови на бази на податоци:
- MS SQL Server,
- MySQL и
- Oracle DB.
