# Член 5
Членот 37 се менува и гласи:
СНа контата од групата 45 - Каматни плаќања се евидентираат каматите по домашни кредити и каматите по странски кредити.
На конто 451-Камати по домашни кредити, се евидентираат трошоците за: камати по девизни штедни влогови; и камати по други домашни кредити.
На конто 452 - Камати по странски кредити се евидентираат трошоците за: камати по мултилатерални кредити; и камати по други странски кредитим.
