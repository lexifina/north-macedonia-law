# Член 58
Офицер може да се унапреди во непосредно повисок чин ако во чинот што го има поминал најмалку:
- во чин потпоручник ... ................... ..две години,
- во чин поручник ... ......................... ..три години,
- во чин капетан... ............................ ...пет години,
- во чин мајор ... ............................... ...пет години,
- во чин потполковник ... ......... ... четири години,
- во чин полковник ... ...................... ... пет години и
- во генералски чин ... ..........................две години.
