# Член 3
По членот 117 се додава нов член 117-а, кој гласи:
„Член 117-а
Инвеститорот од членот 39 на овој закон за пуштање во употреба на опрема вградена во новоизграден објект или за пуштање во употреба на опрема којашто е вградена во постоечки градежен објект, треба да има решение за ставање во употреба на опремата по прв пат издадено од Државниот инспекторат за техничка инспекција по претходно спроведена постапка за ставање по прв пат во употреба на опремата во согласност со Законот за техничка инспекција.“
