# Член 52
Здравствената контрола на учесниците во спортските активности ја врши лекар специјалист по спортска медицина.
Во општините во кои нема специјалист по спортска медицина, здравствената контрола на спортистите ќеја врши лекар - специјалист по општа медицина или специјалист по внатрешни болести.
